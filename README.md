# Ясний поліс

Сайт команди страхових агентів зі Стрия, без імені й прізвища. Вигляд і тексти взято з Guardian_site, підбір поліса, форма-квитанція, години роботи й пам'ятка після ДТП прийшли з демо «Ясний поліс». Усе оформлено у світлих тонах, темної теми немає. Це звичайні файли HTML, CSS і JavaScript: збірки й залежностей для роботи сайту не потрібно.

Опис того, що саме робить сайт і за якими правилами, лежить у `docs/brief.md`. Перелік змін у текстах Guardian лежить у `docs/copy-changes.md`.

## Подивитися на сайті

Найпростіше відкрити `index.html` подвійним кліком. Для повної поведінки (наприклад, `fetch` до Worker) зручніше локальний сервер:

```
python3 -m http.server 8080
```

Потім відкрийте http://localhost:8080.

Заявка з цього сайту іде на справжній Worker із `js/config.js` і приходить у справжній Telegram. Щоб подивитися форму без відправки, зберіть варіант для перегляду (див. нижче «Збірка») або тимчасово зробіть `leadEndpoint` порожнім: тоді форма покаже, як заявка виглядатиме в Telegram, і нікуди її не надішле.

## Що змінювати

Контакти, години роботи й адреси, куди йдуть заявки, лежать в одному місці, `js/config.js`:

- `agency`: назва, місто, телефон, ім'я в Telegram без `@`;
- `hours`: години роботи для кожного дня тижня, `null` означає вихідний, час за київським поясом;
- `callback`: правила вибору часу зворотного дзвінка (ці числа відвідувач не бачить);
- `leadEndpoint`: адреса Cloudflare Worker, зараз стоїть діючий `guardian-telegram-proxy`;
- `sheetEndpoint`: адреса Google Таблиці, порожньо означає, що таблиці немає.

Телефон і Telegram продубльовані в `index.html` (підвал, блок контактів і `<noscript>`), щоб їх було видно без JavaScript: якщо міняєте їх у `config.js`, змініть і там.

Рядки `leadEndpoint` і `sheetEndpoint` залишайте в один рядок, в одинарних лапках і з комою в кінці: скрипт збірки шукає їх саме в такому вигляді.

Усі тексти сторінки (послуги, кроки, питання, пам'ятка після ДТП, питання й результати підбору) лежать у `js/content.js`. Розмітка й заголовки секцій, яких там немає, стоять в `index.html`. Кольори й відступи задано змінними на початку `css/styles.css`.

## Як виставити сайт на GitHub Pages

Це окремий проєкт, тож він живе у своєму новому репозиторії. Старий репозиторій Guardian_site при цьому не змінюється.

1. На GitHub створіть новий репозиторій (наприклад, `guardian-polis`), без README, `.gitignore` і ліцензії.
2. У папці проєкту виконайте:

   ```
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-логін>/<назва-репозиторію>.git
   git push -u origin main
   ```

3. У репозиторії відкрийте Settings, потім Pages. У полі Source оберіть Deploy from a branch, гілку `main` і папку `/ (root)`, збережіть.
4. За хвилину-дві сайт з'явиться за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

Якщо потрібна ваша адреса (домен), додайте її в тому ж розділі Pages у полі Custom domain.

## Worker і Telegram

Діючий Worker працює без жодних змін. Нова форма надсилає йому ті самі поля `name`, `phone`, `type` і `comment`, а відповіді підбору, час дзвінка й канал складає в `comment` окремими рядками («Підбір:», «Рекомендація:», «Час дзвінка:», «Канал:»). У Telegram вони приходять у тексті заявки.

Оновлений Worker, `worker/cloudflare-worker.js`, необов'язковий. Він читає ті самі секрети `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`, а ще:

- перевіряє тип і довжину полів, обрізає зайве;
- будує повідомлення з рядками «Підбір», «Рекомендація», «Дзвінок» і «Канал» із структурованих полів;
- відповідає статусом 502, якщо Telegram повернув помилку, і 400, якщо прийшов зіпсований JSON;
- мовчки ігнорує заявку із заповненим прихованим полем (захист від ботів).

Щоб його поставити, відкрийте свій Worker у Cloudflare, замініть код вмістом цього файлу й збережіть (Deploy). Секрети лишаються на місці. Якщо щось піде не так, поверніть попередню версію з історії розгортань Worker.

## Google Таблиця (необов'язково)

Скрипт `apps-script/Sheet.gs` веде архів заявок у таблиці: Дата, Ім'я, Телефон, Вид страхування, Підбір, Рекомендація, Час дзвінка, Канал, Коментар.

1. Створіть Google Таблицю, відкрийте Розширення, потім Apps Script, вставте вміст `Sheet.gs`.
2. Один раз запустіть функцію `setup()` і дайте дозволи. Вона створить аркуш «Заявки».
3. Розгорніть скрипт як веб-застосунок: виконувати від свого імені, доступ для всіх.
4. Адресу, що закінчується на `/exec`, вставте в `sheetEndpoint` у `js/config.js`.

Токена Telegram у скрипті немає, у Telegram заявку надсилає лише Worker.

## Перевірки

Потрібен Node.js. Для браузерних перевірок ще Playwright і його Chromium: `npm i playwright`, потім `npx playwright install chromium`.

```
npm test        # логіка підбору, години, заявка, Worker, тексти
npm run e2e     # браузерна перевірка (потрібен локальний сервер, див. початок tools/e2e.js)
```

Жодна перевірка не надсилає заявок на справжній Worker: браузерні тести обривають будь-який запит до `workers.dev` і рахують такі спроби, у фінальному рядку їх має бути нуль.

## Збірка в один файл

```
npm run build            # dist/guardian-polis.html: усе в одному файлі, зі справжнім Worker
npm run build:demo       # dist/guardian-polis-demo.html: для показу, заявка нікуди не надсилається
npm run build:artifact   # dist/artifact.html: вміст для публікації на сторінці перегляду
```

Файл із `build:demo` можна безпечно віддавати кому завгодно: у ньому порожні `leadEndpoint` і `sheetEndpoint`, а скрипт збірки зупиняється, якщо в такому файлі лишилася адреса `workers.dev`.

## Що варто підтвердити перед запуском

- Години роботи Пн-Пт 9:00 до 18:00 у `js/config.js` це припущення. Звірте їх із фактичним графіком.
- Telegram у `js/config.js` (поле `telegram`) показується на сайті відкрито. Якщо його ім'я містить прізвище, а сайт має лишатися анонімним, вкажіть нейтральний акаунт.
- Описи покриття в підборі й пам'ятка після ДТП загальні. Звірте їх з умовами страховиків, з якими ви працюєте, і з чинними правилами європротоколу. Сайт прямо каже, що підбір дає загальний орієнтир і не є пропозицією страхування.
